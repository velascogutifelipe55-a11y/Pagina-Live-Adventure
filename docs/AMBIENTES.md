# Configuración de Ambientes

## Ambiente de Desarrollo
- Servidor Web: Apache (XAMPP)
- PHP: Versión 7.4 o superior
- Base de Datos: MySQL 8.0
- URL Base: http://localhost/Live-Adventure

## Ambiente de Pruebas
- Herramienta: Postman
- Pruebas: Unitarias por cada método del controlador
- Datos de prueba: 5 servicios iniciales + reservas de prueba
